# My Daily Task Manager

## Overview
**Software Description:** A simple web app I built to help me manage daily tasks and practice Kaizen - small improvements every day. Users can add tasks, set priority, mark them complete, filter, and delete them.

**Purpose:** I built this to learn JavaScript and to stay organized for school. Before this, I was using paper notes and forgetting things. This app helps me see what I still need to do.

[Software Demo Video](https://youtu.be/kaqpZvROtFc)

## Development Environment

- JavaScript, HTML, CSS
- Day.js library via CDN for dates
